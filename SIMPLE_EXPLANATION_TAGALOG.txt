✅ ANSWER #1: BAKIT 1 BOX LANG?
═══════════════════════════════════════════════════════════════════

SIMPLE LANG BOSS:

Kasi MEMORY TEST yan! Hindi memorization!

ITO ANG LOGIC:
──────────────

PHASE 1: MEMORIZATION (Remember Phase)
  👉 Makita ang 4 colored boxes
  👉 🟦🟥🟩🟨 (lahat i-memorize mo!)
  👉 Remember: Red, Blue, Green, Yellow

PHASE 2: DELAY/PROCESSING (Busy Phase)
  👉 Blank screen OR
  👉 Parity task (Odd/Even numbers)
  👉 Brain busy! Maintain memory!

PHASE 3: TEST (Check Phase) ⭐ ITO ANG 1 BOX LANG!
  👉 Computer shows 1 box lang:  🟦
  👉 Computer mag-ask: "SAME o DIFFERENT?"
  
  TANONG SA PARTICIPANT:
  "Teka, ano ba ang original color sa position na yan?"
  "Blue ba talaga before? O ibang color?"
  
  Kailangan i-compare:
  - Nasa MEMORY mo (original color)
  - Nasa SCREEN ngayon (test color)
  
  PRESS:
  - S key = SAME color (pareho)
  - D key = DIFFERENT color (nag-iba)

PHASE 4: THOUGHT PROBE
  👉 "Ano iniisip mo?"
  👉 Press 1-8 (categories)


═══════════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════════

  Screen: "7"
  Tanong: Odd or Even?
  Answer: Odd → Press F
  
  (Habang nag-parity task, maintain pa rin memory ng colors!)


STEP 3: MEMORY TEST (1 Box Lang!)
──────────────────────────────────
  Computer shows sa Position 2:
  
     🟩 GREEN
  
  ❓ TANONG: "SAME o DIFFERENT?"
  
  Isipin mo:
  - Original sa Position 2: BLUE 🟦
  - Ngayon naipakita: GREEN 🟩
  
  ✅ ANSWER: DIFFERENT! (hindi pareho)
  👉 Press D key


ANOTHER EXAMPLE:

  Isipin mo:
  - Original sa Position 4: YELLOW 🟨
  - Ngayon naipakita: YELLOW 🟨
  
  ✅ ANSWER: SAME! (pareho)
  👉 Press S key

✅ ANSWER #2: TIMING NG ODD/EVEN (Fixed Na!)
═══════════════════════════════════════════════════════════════════

PROBLEMA:
  ❌ Dati: 1.5 seconds lang
  ❌ Kulang ang oras!
  ❌ Hindi maka-respond ng mabilis

SOLUSYON:
  ✅ Updated to: 3.0 seconds
  ✅ Double the time!
  ✅ Enough time na to think and press key

PAANO ANG PARITY TASK:
───────────────────────

Tanong: Odd or Even?

You have 3 SECONDS to:
  1. Basahin ang number (7)
  2. Isipin: Odd ba o Even? (ODD!)
  3. Press F (for Odd)

Timing:
  ┌─────────────────────────────────┐
  │  "7"                            │
  │  F = ODD    J = EVEN            │
