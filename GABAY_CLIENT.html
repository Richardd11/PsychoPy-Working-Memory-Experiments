📥 GABAY PARA SA CLIENT

Step-by-Step Guide - Download hanggang Paggamit

PsychoPy Working Memory Experiments

1

📥 PAG-DOWNLOAD SANG FILES

PINAKA-EASY NA PARAAN:

A. Kadto sa GitHub

https://github.com/Richardd11/PsychoPy-Working-Memory-Experiments

B. I-click ang GREEN BUTTON na "Code"

Makita mo ini sa taas-kamot nga parte sang page

C. I-click ang "Download ZIP"

Mag-download ini sang tanan nga files (~2 MB)

D. I-extract ang ZIP file

  • Right-click sa downloaded ZIP file
  • Click "Extract All..."
  • Choose location (Desktop or Documents)
  • Click "Extract"
✅ TAPOS! May ara na kamo sang tanan nga files!
Folder name: PsychoPy-Working-Memory-Experiments-master/
2

🔧 PAG-INSTALL SANG PSYCHOPY

DOWNLOAD PSYCHOPY STANDALONE:

A. Kadto sa official website

https://www.psychopy.org/download.html

B. Choose your operating system:

  • Windows: Download .exe installer
  • Mac: Download .dmg file
  • Linux: Follow ang instructions sa website

C. I-install ang PsychoPy

  • Double-click ang installer
  • Follow ang installation wizard
  • Default settings okay na
  • Hulaton ang installation (5-10 minutes)

D. I-check kung successful

  • Search "PsychoPy" sa Start Menu
  • Dapat makita mo ang PsychoPy app
✅ TAPOS! PsychoPy installed na!
3

📦 PAG-INSTALL SANG PYTHON PACKAGES

PARA SA EXCEL EXPORT FEATURE:

EASY METHOD: Auto-Install

  1. Kadto sa folder: PsychoPy-Working-Memory-Experiments-master/
  2. Double-click: INSTALL_DEPENDENCIES.bat
  3. Hulaton ang installation (2-5 minutes)
  4. Makita mo: "Installation complete!"

Ano ang ma-install:

  • openpyxl - Para sa Excel files
  • pandas - Para sa data processing
  • matplotlib - Para sa graphs
  • scipy - Para sa statistics
⚠️ NOTE: Kung di nag-work ang batch file, use Command Prompt:
pip install -r requirements.txt
✅ TAPOS! Ready na ang tanan nga packages!
4

🚀 PAANO MAG-RUN SANG EXPERIMENT

PINAKA-EASY NA PARAAN:

Para sa Experiment 1 (Simultaneous):

  1. Kadto sa folder
  2. Double-click: RUN_EXPERIMENT1.bat
  3. Enter participant information:
    • Participant ID: (e.g., P001)
    • Age: (e.g., 25)
    • Gender: (male/female/other)
    • Session: (e.g., 001)
  4. Click "OK"
  5. Experiment mag-start na!

Para sa Experiment 2 (Sequential):

  1. Double-click: RUN_EXPERIMENT2.bat
  2. Same process - enter participant info
⚠️ IMPORTANTE: Close other applications para smooth ang experiment!
✅ RUNNING NA! Follow ang instructions sa screen.

Response Keys (Reminder):

Task Key Meaning
Parity F Odd number
Parity J Even number
Memory S SAME (all 4 colors identical)
Memory D DIFFERENT (at least 1 changed)
Thought Probe 1-8 Category number
Navigation SPACE Continue/Next
Quit ESC Exit experiment
5

📊 PAG-EXPORT SA EXCEL (PROFESSIONAL FORMAT)

CONVERT CSV TO BEAUTIFUL EXCEL:

A. After mag-run sang experiment

May ara CSV file na sa data/ folder

B. Run ang Excel Converter

  1. Kadto sa main folder
  2. Double-click: EXPORT_TO_EXCEL.bat
  3. Hulaton ang conversion (1-2 seconds per file)
  4. Makita mo: "Successfully converted X files"

C. Check ang output

Kadto sa data/ folder:

  • Original: P001_Experiment1_..._data.csv
  • Formatted: P001_Experiment1_..._data_FORMATTED.xlsx
✅ TAPOS! Professional Excel file ready na!

Ano ang Makita Mo sa Excel:

Sheet 1: SUMMARY

  • Participant information
  • Memory accuracy percentage
  • Average reaction times
  • Parity task accuracy
  • Performance by load condition (0, 2, 4)
  • Min/Max values

Sheet 2: RAW DATA

  • All trial data
  • 🟢 Green = Correct (1)
  • 🔴 Red = Incorrect (0)
  • 🟡 Yellow = N/A
  • Centered text, professional formatting
6

🔧 KUNG MAY PROBLEMA

❌ Problem: "Python not found"

Solution: Install PsychoPy Standalone (already includes Python) or download Python from python.org

❌ Problem: "Module not found"

Solution: Run INSTALL_DEPENDENCIES.bat ulit

❌ Problem: "Conditions file not found"

Solution: Make sure ara ang conditions/ folder with CSV files

❌ Problem: "Permission denied" sa Excel

Solution: Close ang Excel file kung bukas, then try ulit

❌ Problem: Data folder not found

Solution: Create manually: Right-click > New > Folder > name it "data"
