❓ COMMON QUESTIONS
================================================================================

Q: Why not include PsychoPy in the GitHub download?
A: It's 500 MB! GitHub is for code (2 MB), not large software.
   Also, PsychoPy updates frequently - better to download latest.

Q: Why not include Python packages?
A: Different systems need different versions.
   Better to download the right version for your system automatically.

Q: Can I run experiments without downloading anything extra?
A: NO. You MUST download PsychoPy at minimum.
   Python packages are needed for Excel export.

Q: Can I download everything at once?
A: NO. Three separate downloads required:
   1. Codebase (GitHub)
   2. PsychoPy (psychopy.org)
   3. Packages (automatic via INSTALL_DEPENDENCIES.bat)

Q: Do I need internet for all of this?
A: YES for initial setup (downloading ~600 MB total)
   NO after setup - experiments run offline

Q: Can I skip installing Python packages?
A: YES if you don't need Excel export
   NO if you want beautiful formatted Excel files
