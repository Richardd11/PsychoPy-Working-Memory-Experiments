================================================================================
  WHY IS THIS HAPPENING?
================================================================================

When you try to run the experiment without PsychoPy:

1. You double-click RUN_EXPERIMENT1.bat
2. It tries to run "python experiment1_simultaneous.py"
3. ❌ Python is not installed (it comes with PsychoPy)
4. Window closes immediately

NEW BEHAVIOR (Fixed):

1. You double-click RUN_EXPERIMENT1.bat
2. It checks: Is Python installed?
3. ❌ NO → Shows error message with instructions
4. ✅ YES → Checks: Is PsychoPy installed?
5. ❌ NO → Shows error message with instructions
6. ✅ YES → Runs the experiment!

================================================================================
  COMMON ERRORS & FIXES
================================================================================

ERROR: "Python is not recognized..."
FIX: Install PsychoPy Standalone first

ERROR: "No module named 'psychopy'"
FIX: Install PsychoPy Standalone first

ERROR: Window closes after "Measuring frame rate..."
FIX: PsychoPy is not installed. Install it first!

ERROR: "Cannot load conditions file"
FIX: Make sure you extracted the ZIP file completely

ERROR: "Module not found: pandas/openpyxl"
FIX: Run INSTALL_DEPENDENCIES.bat
