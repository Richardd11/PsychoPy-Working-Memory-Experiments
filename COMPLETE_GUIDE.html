    Open PsychoPy - you should see the main window with:

    • ✅ Coder view
    • ✅ Runner view

🔵 Experiment 1: Simultaneous Presentation

⭐ Key Feature

All 4 colored squares shown AT THE SAME TIME

📖 What Is It?

In Experiment 1, participants see all 4 colored squares displayed simultaneously (all at once). This tests traditional working memory capacity under different cognitive load conditions.

💡
IMPORTANT: Why Show 4 Boxes but Test Only 1?

This is a WORKING MEMORY TEST!

Phase 1 (Memorization): Show 4 boxes = LEARN all colors
Phase 2 (Test): Show 1 box = CHECK if you remember

Purpose: Measure how well you can hold multiple items in memory!
The Challenge: Remember ALL 4 colors, even though only 1 is tested!

🎬 Trial Structure

⭐
KEY DIFFERENCE vs Experiment 2:
All 4 squares appear AT THE SAME TIME (simultaneous)
Parity task comes AFTER seeing all squares
1. Fixation Cross (+)

Duration: 500ms

Purpose: Focus attention to center

2. Memory Array (ALL 4 SQUARES) ⭐ MEMORIZATION PHASE

Duration: 500ms

Display: 🟦🟥🟩🟨 All together!

Task: Remember ALL 4 colors!

You MUST remember all because you don't know which will be tested!

3. Blank Delay

Duration: 800ms

Maintain memory during blank screen

4. Parity Task (Optional)

Load 0: No task (blank)

Load 2: Judge 2 digits (odd/even)

Load 4: Judge 4 digits (odd/even)

Keys: F = Odd, J = Even

5. Memory Test ⭐ TEST PHASE (Only 1 Box!)

Why only 1 box? This is the TEST, not memorization!

Computer picks 1 random position and shows a color

Your task: Compare the shown color with what you REMEMBER

Question: Same or different color?

Keys: S = Same, D = Different

Example:
- Position 2 was BLUE in memorization
- Test shows GREEN at position 2
- Answer: DIFFERENT (press D)

6. Thought Probe

What were you thinking about?

Keys: 1-8 (8 categories)

🟢 Experiment 2: Sequential Presentation

⭐ Key Feature

4 colored squares shown ONE AT A TIME (sequential)

📖 What Is It?

In Experiment 2, participants see the 4 colored squares presented sequentially (one at a time) with parity judgments interleaved between presentations. This tests serial memory encoding with processing interruption.

💡
SAME PRINCIPLE: 4 Boxes Shown, 1 Box Tested!

Phase 1 (Memorization): Show 4 boxes ONE BY ONE = LEARN all colors
Phase 2 (Test): Show 1 box = CHECK if you remember

The Difference from Exp 1: Items shown sequentially, not simultaneously
Still: You must remember ALL 4 because any one can be tested!

🎬 Trial Structure

⭐
KEY DIFFERENCE vs Experiment 1:
Squares appear ONE AT A TIME (sequential)
Parity task comes BETWEEN each square (interleaved)
1. Fixation Cross (+)

Duration: 500ms

2. Square 1 Only ⭐ MEMORIZATION STARTS

Duration: 500ms

Display: 🟦 (first square only)

Remember this color!

3. Delay + Maybe Parity

200ms delay

If Load > 0: Judge digit (F/J)

4. Square 2 Only ⭐

Duration: 500ms

Display: 🟥 (second square only)

5. Delay + Maybe Parity

200ms delay

If Load > 0: Judge digit (F/J)

6. Square 3 Only ⭐

Duration: 500ms

Display: 🟩 (third square only)

7. Delay + Maybe Parity

200ms delay

If Load > 0: Judge digit (F/J)

8. Square 4 Only ⭐

Duration: 500ms

Display: 🟨 (fourth square only)

9. Delay + Maybe Parity

200ms delay

If Load > 0: Judge digit (F/J)

10. Memory Test ⭐ TEST PHASE (Only 1 Box!)

Same as Experiment 1: Only 1 box shown for testing!

Computer picks 1 random position and shows a color

Your task: Recall which color was at that position

Question: Same or different from what you remember?

Keys: S = Same, D = Different

Example:
- Square 3 was GREEN during presentation
- Test shows YELLOW at position 3
- Answer: DIFFERENT (press D)

11. Thought Probe

Keys: 1-8

📋 Variables (35 total)

Participant Information (5 variables) ▼
  • participant: Participant ID
  • session: Session number
  • date: Date and time
  • age: Participant age
  • gender: Participant gender
Trial Information (4 variables) ▼
  • trial_number: Trial number (1-144)
  • load_condition: Cognitive load (0, 2, or 4)
  • change_condition: change or no_change
  • tested_position: Which square tested (1-4)
Memory Stimuli (6 variables) ▼
  • memory_color_1 to 4: Colors shown
  • original_color: Original color at tested position
  • probe_color: Color shown during test
Parity Task Data (16 variables) ▼

For each of 4 possible digits:

  • parity_digit_N: Digit shown (or NA)
  • parity_response_N: Response (f/j or NA)
  • parity_correct_N: Correct (1/0 or NA)
  • parity_rt_N: Reaction time (seconds or NA)
Memory Test (3 variables) ▼
  • memory_response: Response (s/d or NA)
  • memory_correct: Correct (1/0)
  • memory_rt: Reaction time (seconds or NA)
Thought Probe (3 variables) ▼
  • thought_probe_response: Number pressed (1-8)
  • thought_probe_label: Category name
  • thought_probe_rt: Reaction time (seconds)
Timestamps (3 variables) - NEW! ▼
  • trial_start_time: Trial start (seconds from experiment start)
  • trial_end_time: Trial end (seconds from experiment start)
  • trial_duration: Total trial duration (seconds)

🔧 Troubleshooting

⚠️
Having issues? Most problems have simple solutions!

❌ Common Problems & Solutions

"Shader compilation failed" Error ▼
❌
Problem: Graphics driver compatibility issue
✅
Solution: Use PsychoPy Standalone instead of pip-installed version
  • Download from: psychopy.org/download
  • Standalone has pre-configured graphics settings
Window opens in windowed mode (not fullscreen) ▼
ℹ️
What happens: Yellow warning message, experiment continues in window
✅
Solution: This is OK! Press SPACE to continue
  • Experiment will work fine
  • Timing is still accurate
  • Just slightly smaller display
"Participant ID cannot be empty" ▼
ℹ️
What happens: Dialog appears, experiment quits
✅
Solution: Restart and enter a valid participant ID
  • Example: P001, SUB_042, etc.
  • Cannot be blank or only spaces
"File already exists" Dialog ▼
⚠️
What happens: Data file for this participant already exists

Options:

  • Cancel: Stop without overwriting
  • Overwrite: Replace old file (⚠️ DATA LOSS!)
  • New Session: Create new file with timestamp ✅ RECOMMENDED
Low frame rate warning (< 60 Hz) ▼
⚠️
What happens: Yellow warning before experiment
💡
Solutions:
  • Check monitor settings (should be 60Hz or higher)
  • Update graphics drivers
  • Close other programs
  • If unavoidable, note frame rate in your methods section
Python/Module not found errors ▼
❌
Problem: Missing dependencies
✅
Solution 1 (Recommended): Use PsychoPy Standalone

All dependencies included!

💡
Solution 2 (Advanced): Install dependencies 
pip install psychopy pandas numpy matplotlib seaborn openpyxl
Data file won't save / Permission denied ▼
⚠️
Problem: Permission issues with data folder

Solutions:

Windows: Run as administrator (right-click → Run as administrator)

Mac/Linux: Check folder permissions

chmod 755 data/
