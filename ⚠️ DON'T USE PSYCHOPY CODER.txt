================================================================================
  WHY NOT USE PSYCHOPY CODER?
================================================================================

PsychoPy Coder is designed for:
   ❌ Developing/editing experiment code
   ❌ Testing small code snippets
   ❌ Debugging individual functions

It's NOT designed for:
   ✅ Running complete experiments with participants
   ✅ Managing data files properly
   ✅ Handling errors gracefully

When you run from Coder:
   - The console output window may close immediately
   - Error messages disappear before you can read them
   - Harder to manage data files
   - Working directory may be wrong

When you use the batch files:
   - Everything is configured correctly
   - Error messages stay visible
   - Data files go to the right place
   - Console window stays open

================================================================================
  WHAT IF BATCH FILES DON'T WORK?
================================================================================

If double-clicking the batch files doesn't work:

1. Run setup test first:
   Double-click: TEST_SETUP.bat

2. If it says PsychoPy is not installed:
   Double-click: SETUP_WIZARD.bat
   Choose option 2 to install

3. If it says packages are missing:
   Double-click: INSTALL_DEPENDENCIES.bat

4. Try running the experiment again:
   Double-click: RUN_EXPERIMENT1.bat

================================================================================
  TROUBLESHOOTING
================================================================================

Problem: Batch file doesn't do anything when I double-click
Solution: PsychoPy is not installed. Run SETUP_WIZARD.bat first.

Problem: "Python is not recognized" error
Solution: Install PsychoPy Standalone from psychopy.org/download.html

Problem: "Cannot load conditions file" error
Solution: Make sure you extracted the ZIP file completely

Problem: Window still closes immediately
Solution: Run TEST_SETUP.bat to see what's wrong
