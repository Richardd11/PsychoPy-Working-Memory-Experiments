================================================================================
  EXPERIMENT DESIGN SUMMARY
================================================================================

EXPERIMENT 1: SIMULTANEOUS PRESENTATION
   Memory Phase: All 4 colored squares shown TOGETHER (500ms)
   Delay: 800ms mask delay
   Distractor: 0/2/4 parity judgments (3s each)
   Test: All 4 squares shown again
   Question: "Are all 4 colors the SAME as before?"
   Response: S = Same | D = Different

EXPERIMENT 2: SEQUENTIAL PRESENTATION  
   Memory Phase: 4 colored squares shown ONE BY ONE (500ms each, 200ms ISI)
   Distractor: 0/2/4 parity judgments (3s each)
   Test: All 4 squares shown TOGETHER again
   Question: "Are all 4 colors the SAME as before?"
   Response: S = Same | D = Different

COMMON FEATURES:
   - 144 trials (breaks every 36 trials)
   - 6 practice trials before main
   - Load conditions: 0, 2, 4 digits
   - Change conditions: 50% same, 50% different
   - Thought probe after each trial
   - English instructions
   - All timing validated

TIMING CONSTANTS:
   FIXATION: 0.5s
   MEMORY_DISPLAY: 0.5s per item
   MASK_DELAY: 0.8s (Exp 1 only)
   ISI: 0.2s
   PARITY_TIMEOUT: 3.0s (changed from 1.5s per client request)
   MEMORY_TEST_TIMEOUT: 5.0s
   LOAD_0_BLANK: 6.0s
